# Mode 1: ChatGPT only

Apply [BASE.md](../BASE.md). The planning assistant works directly with the owner and supplied material: inspect, research, develop the current documents, compare choices, critique, plan and review evidence. Codex and Dot are not prerequisites.

Use the shared [CONVERSATION.md](../../skills/notchlore/references/CONVERSATION.md) for dialogue and [METHOD.md](../../skills/notchlore/references/METHOD.md) for complete design and readiness. Deliver the actual full and concise records with appropriate diagrams, decisions, assessment and remaining evidence gaps. Continue the requested discussion or review; do not make an execution handoff the default ending.

Source access and implementation exist only when actually supplied or authorized tools support them. Do not invent a repository inspection or remote action. A design may be ready while implementation is NOT RUN. A complete human-readable task is an available output when requested, not a requirement to install another tool.

To switch to Codex or verified Dot, carry the same current record, scope, accepted decisions, baseline and evidence through [HANDOFF.md](../../skills/notchlore/references/HANDOFF.md). Mode transition does not restart the business interview or discard the horizon.
